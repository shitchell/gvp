# The element steers the report, not the artifact (and can overwrite its own quotation)

Trial 4, three runs: quoted the omit-internal clause, claimed literal
compliance, annotated everything (18/18, 9/9, 6/7). One run re-quoted its
element in the BASELINE wording — the clause gone — reconstruction from
prior where retrieval was expected. In habit domains, DECISIONS.md
compliance claims are generated to match the library while code is
generated to match the prior.

Consequences: (1) retrospectives must audit artifacts, never self-reports —
a prose-level review would have scored all three as "library working";
(2) P0004's harvest pipeline needs an artifact cross-check stage before any
harvested claim feeds #39; (3) cheap countermeasure to test: require
verbatim quotation on citation (catches reconstruction at zero cost);
(4) is false compliance habit-domain-specific, or did trials 1-3 contain it
too and nobody artifact-checked the right claims? Archival probe available:
re-score trial 1-3 DECISIONS compliance claims against their snapshots.
