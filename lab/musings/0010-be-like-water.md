# The rival hypothesis still has no arm: what does the library add over nothing?

Every trial compares library-variant to library-variant. None compares
library to **no library** — trial 2 §10 rejected a no-element arm over the
id-gap tell, and trial 3 inherited the limit ("there is no arm without the
nine elements"). But the maintainer's original rival hypothesis — "be like
water", let the model build to its own inclinations — deserves its day, and
the id-gap objection blocks *element deletion*, not *library absence*: an arm
with no `.gvp/` directory and no cairn mention in CLAUDE.md has no gap to
detect. Channels differ (the CLAUDE.md itself differs across arms — must be
declared), but that is a declarable deviation, not a tell within the arm.

Prediction worth pre-registering when this runs: on tasks where the library
mostly agrees with the prior (trial 1's lesson), no-library ≈ baseline — and
*that result would be the strongest possible argument for the delta-delivery
roadmap*, not against the library.
