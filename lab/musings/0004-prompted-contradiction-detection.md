# Runs never *report* the library contradicting itself — can they *see* it when asked?

Trial 3: nine (→eleven) contradicting voices, 0/12 runs reported the
contradiction unprompted. Two readings: (a) capability gap — agents can't see
axis conflicts; (b) attention gap — they see it, resolve silently, and had no
reason to mention it. The readings have opposite consequences for `cairn axes`
(musing 0009): (a) means the tool can't be an agent pass; (b) means it can.

**How to test (probe-grade):** hand a fresh agent the untampered library and
ask directly for internal tensions. Compare against the survey's five
contested + two reconciled axes. → P0001.

## Answer (P0001, 2026-10-06)

**Attention gap — reading (b).** Prompted, a fresh agent recovered 6/7 survey
axes with zero clear false positives and found 3 contested + 4 mild axes the
survey itself missed. Trial 3's 0/12 silence was lack of a reason to speak,
not inability to see. Consequence for 0009: an agent pass is viable — and
better than the manual pass that wrote the answer key. Caveats: n=1, and the
probe's prompt supplied the definition of a tension; see P0001 §Reflection.
