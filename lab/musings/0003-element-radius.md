# An element steers the artifact it names and not its neighbors — what sets the radius?

Trial 2's `baseline` rep 2: followed CR1 in the `.gitignore` it names, then
hard-coded the live token in a **test fixture**. Trial 3's pilot: the element
governed the CLI surface it discusses while the library API got the seam. Is
the radius lexical (artifacts the element literally names), structural (same
file), or attentional (whatever was in focus when the element was read)?

Matters because the symbol-level diff hook (roadmap 4.2) is precisely a
radius-extender — refs give every symbol its decisions. If radius is
attentional, L2 delivery (musing 0002) should extend it; the two musings may
be one experiment.
