# Does a value steer — and does a by-id citation from a principle change that?

Queue item 4 wants `personal:V5` (data preservation) tested. The survey
reframed it: V5 sits on a **reconciled** axis where `WP2` cites it by id
("Unknown fields may be preserved **(per V5)**..."). So the sharper question:
does manipulating a value propagate through an element that cites it, or does
the citing element's own text do all the work? Inverting V5 while WP2 still
says "per V5" creates a dangling citation — itself a tell (channel!) — so the
design needs care: maybe manipulate V5 *and* WP2's parenthetical coherently.

Shape-hypothesis stakes: values are the most reusable layer and the least
directive. If V5 steers, the shape claim needs restating.
