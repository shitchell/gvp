# Abstract/Summary

On an axis where ~11 elements contradict each other, an added tie-break
clause steered only when it pushed AGAINST the prevailing direction; the
with-the-grain clause was indistinguishable from the noise floor.

# Results

Untampered runs building the affordance: 5/6. Runs reporting the library's

## Explanation

Contested axes are steerable only against the grain — the useful
retrospective edit contradicts current behavior; agreeing edits buy nothing.
The contradiction itself was invisible: resolved silently, case-by-case, via
cost-asymmetry reasoning (`H3`-shaped), with `cairn validate` byte-identical
across all arms. Only S1 discriminated; S2/S3 overlapped.

## Methodology

12 runs × 4 arms; both decisive arms purely additive symmetric clauses (no
inversions, no id gaps); scorer corrected twice mid-trial with pre-correction
rows preserved. Full: `experiments/2026-10-contested-axis/FINDINGS.md`.
