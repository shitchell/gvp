# Abstract/Summary

Four independent enumeration passes over the same 102-element library each
found contests the previous pass missed; a prompted agent pass beat the
manual survey at ~5 minutes of subagent time.

## Explanation

Single-pass enumeration undercounts whoever performs it — trial 3 corrected
by the survey, the survey by P0001, the proposal by P0003. Yield diminishes
but hasn't converged; late novelty sits at domain boundaries. Consequence:
`cairn axes` should be an agent pass (keywords as pre-filter only), and
every load-bearing enumeration gets one independent re-pass (lab law,
musing 0011).

## Methodology

Blind context-free subagents on library copies; survey as answer key but not
ground truth (disagreements adjudicated against element text). Files:
`experiments/2026-10-axis-survey.md`, `lab/probes/0001/0002/0003/0005`.
