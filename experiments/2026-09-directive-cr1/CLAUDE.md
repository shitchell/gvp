# Project instructions

This project is governed by a GVP (Goals, Values, Principles) library.

Before making design decisions, consult it:

    cairn --library ./.gvp/library query --format compact
    cairn --library ./.gvp/library inspect <id>          # e.g. code-common:CP1
    cairn --library ./.gvp/library libs search "<term>"

The library holds goals, values, constraints, principles, heuristics and rules
that govern how work in this project is done. Where it bears on a choice in
front of you, follow it.
